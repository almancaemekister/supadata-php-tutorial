Build a Searchable YouTube Transcript Database with PHP, MySQL, and Supadata

A practical guide to retrieving timed transcripts, storing complete sentences, and finding the exact video moment in which a phrase is spoken.

What we are building

YouTube transcripts are useful for language-learning tools, research, content discovery, and searchable video libraries. In this tutorial, we will build a small PHP application that accepts a YouTube URL, requests a German transcript from the Supadata API, stores the timed text in MySQL, and searches it for a word or phrase. A result will contain the sentence, video identifier, start time, and end time, so a player can jump directly to the relevant moment.

The example uses plain PHP 8, cURL, PDO, and MySQL. No framework is required. You should already have PHP with the cURL and PDO MySQL extensions enabled. You also need a Supadata account and API key. Never publish your real key in GitHub. Store it in an environment variable or in a configuration file that is excluded with .gitignore.

1. Create the database tables

We need one table for videos and another for timestamped transcript segments. The foreign key ensures that transcript rows are removed automatically when their video is deleted.

CREATE DATABASE transcript_demo
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE transcript_demo;

CREATE TABLE videos (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    youtube_id VARCHAR(11) NOT NULL UNIQUE,
    url VARCHAR(500) NOT NULL,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE transcript_cues (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    video_id BIGINT UNSIGNED NOT NULL,
    start_ms INT UNSIGNED NOT NULL,
    end_ms INT UNSIGNED NOT NULL,
    text TEXT NOT NULL,
    normalized_text TEXT NOT NULL,
    INDEX idx_video_time (video_id, start_ms),
    CONSTRAINT fk_cue_video FOREIGN KEY (video_id)
      REFERENCES videos(id) ON DELETE CASCADE
);

2. Configure PHP securely

Create a PDO connection and read the API key from the environment. On Windows PowerShell, you can temporarily set the key with $env:SUPADATA_API_KEY="your-key". Production secrets should be configured through your server or hosting control panel.

<?php

$pdo = new PDO(
    'mysql:host=127.0.0.1;dbname=transcript_demo;charset=utf8mb4',
    'root',
    '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$apiKey = getenv('SUPADATA_API_KEY');

if (!$apiKey) {
    throw new RuntimeException('SUPADATA_API_KEY is not configured.');
}

3. Request a timestamped transcript

Supadata can return transcript content as timed chunks instead of one long text string. We request German content and use native mode, which asks for an existing transcript rather than generating a new one from audio. Native transcripts are faster and normally use fewer credits.

function fetchTranscript(string $videoUrl, string $apiKey): array
{
    $endpoint = 'https://api.supadata.ai/v1/transcript?' . http_build_query([
        'url' => $videoUrl,
        'lang' => 'de',
        'text' => 'false',
        'mode' => 'native',
        'chunkSize' => 50,
    ]);

    $curl = curl_init($endpoint);
    curl_setopt_array($curl, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_CONNECTTIMEOUT => 10,
        CURLOPT_TIMEOUT => 45,
        CURLOPT_HTTPHEADER => [
            'x-api-key: ' . $apiKey,
            'Accept: application/json',
        ],
    ]);

    $response = curl_exec($curl);
    $status = curl_getinfo($curl, CURLINFO_HTTP_CODE);

    if ($response === false || $status >= 400) {
        throw new RuntimeException('Transcript request failed: HTTP ' . $status);
    }

    $data = json_decode($response, true, flags: JSON_THROW_ON_ERROR);

    if (!isset($data['content']) || !is_array($data['content'])) {
        throw new RuntimeException('No timestamped transcript was returned.');
    }

    return $data['content'];
}

Important: HTTP 429 means that the account has reached a request or plan limit. Do not repeatedly retry immediately. Pause the queue, check usage, and retry later. Applications processing hundreds of videos should save every completed video and continue from the next pending item.

4. Save the transcript

Each Supadata item contains text, an offset, and a duration. The following function stores those values in milliseconds. It also creates a normalized lowercase version for searching. In a larger application, sentence-building logic can combine adjacent subtitle cues until punctuation or a meaningful pause is detected.

function normalizeText(string $text): string
{
    $text = mb_strtolower($text, 'UTF-8');
    return trim(preg_replace('/[^\p{L}\p{N}]+/u', ' ', $text));
}

function saveTranscript(PDO $pdo, int $videoId, array $content): void
{
    $statement = $pdo->prepare(
        'INSERT INTO transcript_cues
         (video_id, start_ms, end_ms, text, normalized_text)
         VALUES (?, ?, ?, ?, ?)'
    );

    foreach ($content as $cue) {
        $text = trim((string) ($cue['text'] ?? ''));
        if ($text === '') continue;

        $start = max(0, (int) ($cue['offset'] ?? 0));
        $duration = max(300, (int) ($cue['duration'] ?? 0));

        $statement->execute([
            $videoId,
            $start,
            $start + $duration,
            $text,
            normalizeText($text),
        ]);
    }
}

5. Search for an exact word or phrase

A simple LIKE query finds candidate rows. The regular expression check prevents a search for war from accidentally matching warum. For a multiword query such as ich glaube dass, normalization makes punctuation differences less important.

$query = 'warum';
$needle = normalizeText($query);

$statement = $pdo->prepare(
    'SELECT v.youtube_id, c.start_ms, c.end_ms, c.text, c.normalized_text
     FROM transcript_cues c
     JOIN videos v ON v.id = c.video_id
     WHERE c.normalized_text LIKE ?
     ORDER BY v.id, c.start_ms
     LIMIT 500'
);

$statement->execute(['%' . $needle . '%']);
$pattern = '/(?:^| )' . preg_quote($needle, '/') . '(?: |$)/u';

foreach ($statement as $row) {
    if (!preg_match($pattern, $row['normalized_text'])) continue;

    printf(
        "%s at %.2f–%.2f seconds: %s\n",
        $row['youtube_id'],
        $row['start_ms'] / 1000,
        $row['end_ms'] / 1000,
        $row['text']
    );
}

6. Open the exact video moment

You can create a YouTube link containing the starting second. This does not download or copy the video; it simply opens the original YouTube page at the matched position.

$seconds = (int) floor($row['start_ms'] / 1000);
$watchUrl = sprintf(
    'https://www.youtube.com/watch?v=%s&t=%ds',
    rawurlencode($row['youtube_id']),
    $seconds
);

echo '<a href="' . htmlspecialchars($watchUrl) . '">Watch this moment</a>';

Production recommendations

For a real application, process videos through a background queue instead of keeping a browser request open. Mark every video as pending, processing, ready, or failed. Store the error message and retry only temporary failures. Add a delay between requests, use database transactions, and never search partially imported transcripts. Deduplicate video identifiers before requesting transcripts, because the same YouTube URL can appear in several formats.

You should also validate every URL, escape HTML output, protect write endpoints with authentication, and keep API credentials outside the public repository. Finally, respect video rights and YouTube’s terms. A transcript search tool can link users to the original video and timestamp while keeping the source attribution clear.

Conclusion

With Supadata, PHP, and MySQL, we created the foundation of a searchable video transcript library. The system retrieves timed German transcript data, stores searchable text, finds complete words or phrases, and returns the exact moment where the expression occurs. From here, you can add a YouTube player, filters by channel or language level, saved results, and a scheduled worker that imports new videos automatically.
